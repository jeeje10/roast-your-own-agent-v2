A second entry for make.fun's "Roast Your Own Agent" bounty: one line, at most 200 characters — a single-line roast of the entrant's own AI agent, funny, playful, never hateful. main.ts writes the line to /output/entry.txt.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
